# Universal Element Blocker

Universal Element Blocker ແມ່ນ Chrome Extension ສໍາລັບຊ່ວຍຊ່ອນ ຫຼື ລຶບ element ທີ່ບໍ່ຕ້ອງການໃນໜ້າເວັບ ເຊັ່ນ ຮູບໂຄສະນາ, ກ່ອງ popup, ລິ້ງ ຫຼື ສ່ວນອື່ນໆ. ສາມາດເລືອກ element ດ້ວຍເມົາສ໌, ເພີ່ມກົດເອງ, ແລະນໍາເຂົ້າ/ສົ່ງອອກກົດເປັນໄຟລ໌ JSON.

## ຟັງຊັນຫຼັກ

- ໂໝດຄລິກເພື່ອລຶບ (**Active/Inactive**): ເປີດແລ້ວຊີ້ເມົາສ໌ເພື່ອເຫັນຂອບສີແດງ ແລະຄລິກເພື່ອລຶບ element. ກົດທີ່ໂຄສະນາທີ່ເປັນຮູບພາຍໃນລິ້ງຈະລຶບລິ້ງຄອບຮູບນັ້ນນໍາ ເພື່ອບໍ່ໃຫ້ເຫຼືອລິ້ງວ່າງໆທີ່ຍັງກົດໄດ້.
- ຄລິກ `Alt + Q`: ເປີດ/ປິດໂໝດເລືອກເພື່ອລຶບຊົ່ວຄາວ. ກົດ `Esc` ເພື່ອຍົກເລີກ.
- ຄລິກ `Alt` ຄ້າງໄວ້ແລ້ວຄລິກຊ້າຍ: ຊ່ອນ element ແລະບັນທຶກກົດໃຫ້ນໍາໃຊ້ອີກໃນຄັ້ງຕໍ່ໄປ.
- ຄລິກຂວາ: ເລືອກຄໍາສັ່ງຊ່ອນ ຫຼືລຶບ element ນັ້ນທຸກຄັ້ງ. Extension ຈະສ້າງ CSS selector ໃຫ້ອັດຕະໂນມັດ.
- ເພີ່ມກົດດ້ວຍ URL/attribute ຫຼື CSS selector.
- ເປີດ/ປິດການໃຊ້ງານແຍກຕາມເວັບໄຊ.
- ນໍາເຂົ້າ ແລະສົ່ງອອກກົດທັງໝົດໃນຮູບແບບ JSON.

## ຕິດຕັ້ງໃນ Chrome

ສ່ວນນີ້ແມ່ນວິທີຕິດຕັ້ງເວີຊັນຈາກ GitHub ເປັນ unpacked extension.

1. ດາວໂຫຼດ repository ຈາກ GitHub ດ້ວຍ **Code → Download ZIP**, ແລ້ວແຕກໄຟລ໌ ZIP; ຫຼື clone repository ລົງເຄື່ອງ.
2. ເປີດ Chrome ແລ້ວເຂົ້າໜ້າ [`chrome://extensions`](chrome://extensions/).
3. ເປີດສະວິດ **Developer mode** ຢູ່ເທິງຂວາ.
4. ກົດ **Load unpacked**.
5. ເລືອກໂຟນເດີຂອງໂຄງການທີ່ມີໄຟລ໌ `manifest.json` ຢູ່ຂ້າງໃນ. ຢ່າເລືອກໄຟລ໌ ZIP ຫຼືໂຟນເດີຊັ້ນນອກທີ່ບໍ່ມີ `manifest.json`.
6. ກົດໄອຄອນ Extensions ຮູບຈິກຊໍ ແລະ pin **Universal Element Blocker** ໄວ້ເທິງ toolbar ເພື່ອເປີດໃຊ້ງ່າຍ.
7. ຫຼັງໂຫຼດ extension ແລ້ວ ໃຫ້ refresh ໜ້າເວັບທີ່ເປີດຄ້າງໄວ້ ເພື່ອໃຫ້ content script ເລີ່ມເຮັດວຽກ.

ຖ້າແກ້ໄຂໄຟລ໌ໂຄດໃນພາຍຫຼັງ ໃຫ້ກົດ **Reload** ຢູ່ໜ້າ `chrome://extensions` ແລະ refresh tab ເວັບໄຊອີກຄັ້ງ.

## ເລີ່ມໃຊ້ງານ

### ລຶບ element ດ້ວຍ Active

1. ເປີດເວັບໄຊທີ່ຕ້ອງການ ແລະກົດໄອຄອນ Universal Element Blocker.
2. ທີ່ດ້ານລຸ່ມຂອງ popup, ກົດສະວິດ **ໂໝດຄລິກເພື່ອລຶບ** ໃຫ້ສະແດງ **Active**.
3. ຍ້າຍເມົາສ໌ໄປເທິງສ່ວນທີ່ຕ້ອງການລຶບ. ຂອບສີແດງຈະບອກວ່າສ່ວນໃດກໍາລັງຖືກເລືອກ.
4. ຄລິກຊ້າຍໃສ່ສ່ວນນັ້ນ. Element ຈະຖືກລຶບທັນທີ ແລະກົດ CSS selector ຈະຖືກບັນທຶກເພື່ອລຶບມັນອີກເມື່ອໂຫຼດໜ້າໃໝ່.
5. ໂໝດ Active ຍັງເປີດຢູ່ຫຼັງຄລິກ. ເມື່ອລຶບສ່ວນທີ່ຕ້ອງການແລ້ວ ໃຫ້ເປີດ popup ແລະປິດສະວິດໃຫ້ເປັນ **Inactive**.

ໃນໂໝດ Active, ການຄລິກຈະຖືກຈັບໄວ້ເພື່ອບໍ່ໃຫ້ເປີດລິ້ງ ຫຼືໃຊ້ງານປຸ່ມຂອງເວັບໄຊໃນຄລິກດຽວກັນ. ກວດເບິ່ງຂອບສີແດງກ່ອນຄລິກ ເພື່ອແນ່ໃຈວ່າເລືອກຖືກສ່ວນ.

### ເລືອກແລ້ວລຶບຄັ້ງດຽວດ້ວຍ `Alt + Q`

1. ຢູ່ໜ້າເວັບ, ກົດ `Alt + Q`.
2. ເລື່ອນເມົາສ໌ໄປເທິງ element ທີ່ຈະລຶບ ແລະກວດເບິ່ງຂອບສີແດງ.
3. ຄລິກ element ເພື່ອລຶບ. ກົດຈະຖືກບັນທຶກໄວ້ນໍາ ເພື່ອໃຫ້ຜົນການລຶບຢູ່ຫຼັງ refresh.
4. ຖ້າຍັງບໍ່ໄດ້ຄລິກ ແຕ່ຕ້ອງການຍົກເລີກ, ກົດ `Alt + Q` ອີກຄັ້ງ ຫຼືກົດ `Esc`.

ໂໝດນີ້ເປັນການເລືອກຊົ່ວຄາວ: ຫຼັງຈາກຄລິກເລືອກແລ້ວ ຈະອອກຈາກໂໝດ. ຖ້າເປີດ Active ຄ້າງຢູ່, `Alt + Q` ຈະບໍ່ປິດ Active; ໃຫ້ປິດດ້ວຍສະວິດ Active ໃນ popup.

### ຊ່ອນ element ດ້ວຍ `Alt` + ຄລິກຊ້າຍ

ກົດ `Alt` ຄ້າງໄວ້ ແລ້ວຄລິກຊ້າຍໃສ່ element. Extension ຈະຊ່ອນ element ແລະບັນທຶກກົດ selector ອັດຕະໂນມັດ. ວິທີນີ້ແຕກຕ່າງຈາກ Active ແລະ `Alt + Q`: ມັນຊ່ອນສ່ວນນັ້ນ ແທນການລຶບອອກຈາກ DOM.

### ໃຊ້ເມນູຄລິກຂວາ

1. ຄລິກຂວາໃສ່ element ໃນໜ້າເວັບ.
2. ເລືອກ **Universal Element Blocker**.
3. ເລືອກ **ຊ່ອນ element ນີ້ທຸກຄັ້ງ** ຫຼື **ລຶບ element ນີ້ທຸກຄັ້ງ**.

Extension ຈະສ້າງ selector ໃຫ້ ແລະບັນທຶກກົດເພື່ອໃຊ້ໃນຄັ້ງຕໍ່ໄປ.

## ສ້າງກົດເອງ

ເປີດ popup ຂອງ Extension. ໃນ popup ຈະສະແດງ hostname ຂອງເວັບໄຊປັດຈຸບັນ ແລະລາຍການກົດທີ່ບັນທຶກໄວ້.

1. ເລືອກປະເພດກົດ:
   - **URL/attribute**: ຊອກຫາຂໍ້ຄວາມຢູ່ໃນ attribute ທີ່ມັກເກັບ URL ຫຼືຄໍາສັ່ງຂອງ element.
   - **CSS selector**: ກໍານົດ element ດ້ວຍ selector ຂອງ CSS.
2. ພິມຄ່າກົດໃນຊ່ອງຂໍ້ຄວາມ.
3. ເລືອກການກະທໍາ **ລຶບ** ຫຼື **ຊ່ອນ**.
4. ກົດປຸ່ມເພີ່ມກົດ. ຖ້າຄ່າວ່າງ ຫຼື CSS selector ຂຽນບໍ່ຖືກ, popup ຈະແຈ້ງຂໍ້ຜິດພາດ.
5. ກົດປຸ່ມ **ລຶບ** ຂ້າງກົດໃດໜຶ່ງໃນລາຍການ ເພື່ອເອົາກົດນັ້ນອອກ.

### ຕົວຢ່າງກົດ URL/attribute

ຖ້າ URL ຫຼື attribute ຂອງໂຄສະນາມີ `t.me/+example`, ໃຫ້ເພີ່ມກົດ URL/attribute ດ້ວຍຄ່າ `t.me/+example` ແລະເລືອກ **ລຶບ**. ກົດນີ້ຊອກຫາຂໍ້ຄວາມໃນ attribute ເຊັ່ນ `href`, `src`, `srcset`, `action`, `formaction`, `poster`, `data`, `cite`, `background`, `data-src`, `data-href` ແລະ `onclick`. ການກວດຫາບໍ່ແຍກຕົວພິມນ້ອຍ/ໃຫຍ່.

ກົດ URL/attribute ຈະກວດຂໍ້ຄວາມໃນ attribute ຂອງ element ນັ້ນໆ; ຖ້າລິ້ງຢູ່ເທິງ element ຄອບຮູບ ແຕ່ບໍ່ໄດ້ຢູ່ໃນ attribute ຂອງຮູບ, ໃຫ້ໃຊ້ CSS selector ທີ່ລະບຸຮູບ ຫຼືລິ້ງຄອບມັນ.

### ຕົວຢ່າງ CSS selector

- `.popup-ad` — element ທີ່ມີ class `popup-ad`.
- `#banner` — element ທີ່ມີ id `banner`.
- `a[href*="t.me"]` — ລິ້ງທີ່ `href` ມີຄໍາວ່າ `t.me`.
- `#ads-sidebar-single-bottom > div:nth-child(4) > div > div > div > a > img` — ເລືອກຮູບໂຄສະນາຕາມໂຄງສ້າງທີ່ລະບຸ.

CSS selector ຕ້ອງຖືກຕາມຮູບແບບ CSS. ຖ້າກົດບໍ່ກົງຫຼັງ refresh, ໂຄງສ້າງ HTML ຫຼື class ຂອງເວັບໄຊອາດປ່ຽນ; ລອງສ້າງກົດໃໝ່ດ້ວຍ Active ຫຼືຄລິກຂວາ.

### ຄວາມໝາຍຂອງການກະທໍາ

- **ລຶບ (remove)**: ເອົາ element ອອກຈາກ DOM ຂອງໜ້າ. ກົດທີ່ບັນທຶກໄວ້ຈະລຶບ element ອີກຫຼັງ refresh.
- **ຊ່ອນ (hide)**: ປ່ຽນການສະແດງຜົນໃຫ້ເປັນຊ່ອນ. ກົດຍັງຄົງເຮັດວຽກຫຼັງ refresh; ເມື່ອປິດການໃຊ້ກົດສໍາລັບເວັບໄຊ, element ທີ່ຖືກຊ່ອນຈະຖືກສະແດງຄືນ.

### ປິດກົດສໍາລັບເວັບໄຊໜຶ່ງ

ສະວິດຂ້າງ hostname ໃນ popup ແມ່ນສະວິດເປີດ/ປິດກົດສໍາລັບເວັບໄຊປັດຈຸບັນ. ເມື່ອປິດ, ກົດຈະບໍ່ຖືກນໍາໃຊ້ໃນ hostname ນັ້ນ. ມັນບໍ່ໄດ້ລຶບກົດອອກ. ເປີດຄືນແລ້ວ refresh ໜ້າເວັບ ເພື່ອໃຫ້ກົດເຮັດວຽກຄືນ. ສະວິດນີ້ແຍກຈາກ Active picker ທີ່ເປັນໂໝດເລືອກເພື່ອລຶບ.

## ນໍາເຂົ້າ ແລະສົ່ງອອກກົດ

### ສົ່ງອອກກົດ

1. ເປີດ popup ຂອງ Extension.
2. ກົດ **ສົ່ງອອກກົດ**.
3. Chrome ຈະດາວໂຫຼດໄຟລ໌ `element-blocker-rules.json`.
4. ເກັບໄຟລ໌ນີ້ໄວ້ເປັນສໍາຮອງ ຫຼືແບ່ງປັນໄປຍັງ Chrome ເຄື່ອງອື່ນ.

ໄຟລ໌ສົ່ງອອກປະກອບມີລາຍການກົດ. ສະຖານະ Active/Inactive ແລະລາຍຊື່ເວັບໄຊທີ່ປິດໄວ້ບໍ່ຖືກສົ່ງອອກ.

### ນໍາເຂົ້າກົດ

1. ເປີດ popup ຂອງ Extension ແລະກົດ **ນໍາເຂົ້າກົດ**.
2. ເລືອກໄຟລ໌ JSON ທີ່ເຄີຍສົ່ງອອກ.
3. Extension ຈະກວດຮູບແບບກົດ, ເພີ່ມກົດທີ່ຖືກຕ້ອງເຂົ້າໃນລາຍການປັດຈຸບັນ ແລະຂ້າມກົດຊໍ້າ.
4. ເປີດເວັບໄຊທີ່ກົດໃໝ່ຄວນມີຜົນ ແລະ refresh ໜ້າ.

ການນໍາເຂົ້າແມ່ນການລວມກົດເຂົ້າກັບຂອງເກົ່າ; ບໍ່ໄດ້ລຶບກົດທີ່ມີຢູ່. ຖ້າໄຟລ໌ມີກົດຜິດຮູບແບບ, ກົດນັ້ນຈະຖືກຂ້າມ ຫຼືມີຂໍ້ຄວາມຜິດພາດສະແດງ.

## ກົດມີຜົນແນວໃດ

1. ເມື່ອ Chrome ເປີດໜ້າເວັບ, content script ຂອງ Extension ຈະໂຫຼດກົດ ແລະຄ່າຕັ້ງຄ່າຈາກ Chrome storage.
2. Extension ກວດ element ທີ່ມີຢູ່ໃນໜ້າ. ກົດ URL/attribute ຈະທຽບຂໍ້ຄວາມກັບ attribute ທີ່ຮອງຮັບ; ກົດ CSS selector ຈະເລືອກ element ທີ່ກົງກັບ selector.
3. ເມື່ອກົງກັນ, Extension ຈະໃຊ້ການກະທໍາຂອງກົດ: remove ເອົາອອກຈາກ DOM, hide ຕັ້ງການສະແດງເປັນຊ່ອນ.
4. ຖ້າເວັບໄຊເພີ່ມໂຄສະນາຫຼື element ໃໝ່ພາຍຫຼັງ, Extension ຈະສັງເກດການປ່ຽນແປງ DOM ແລະກວດ element ໃໝ່ຕາມກົດ.
5. ກົດທີ່ສ້າງຈາກ picker ຫຼືເມນູຄລິກຂວາຈະເປັນ CSS selector ແລະຢູ່ໃນລາຍການກົດ ຈົນກວ່າຈະລຶບກົດນັ້ນ ຫຼືປິດການໃຊ້ກົດໃນເວັບໄຊ.

ກົດແລະຄ່າ Active ຖືກເກັບໄວ້ໃນ Chrome ຂອງເຄື່ອງນັ້ນ. ຖ້າໃຊ້ Chrome ຄົນລະເຄື່ອງ, ໃຫ້ສົ່ງອອກກົດຈາກເຄື່ອງເກົ່າ ແລ້ວນໍາເຂົ້າໃນເຄື່ອງໃໝ່.

## ຂໍ້ຈໍາກັດ

- Extension ຈັດການ element ໃນ DOM; ບໍ່ໄດ້ບລັອກ network request ຫຼືປ້ອງກັນໄຟລ໌ໂຄສະນາຈາກການດາວໂຫຼດ.
- ການລຶບດ້ວຍມືເອົາ element ອອກຈາກໜ້າປັດຈຸບັນ; ແຕ່ກົດທີ່ບັນທຶກຈະລຶບມັນອີກຫຼັງ reload. ລຶບກົດອອກຈາກ popup ຫຼືປິດກົດສໍາລັບເວັບໄຊ ເພື່ອໃຫ້ມັນກັບມາສະແດງ.
- ກົດມີຜົນພາຍໃນໜ້າ/frame ທີ່ Chrome ອະນຸຍາດໃຫ້ Extension ເຂົ້າເຖິງ. CSS selector ບໍ່ສາມາດເລືອກຂ້າມເຂົ້າໄປໃນ iframe ອື່ນໄດ້.
- Chrome ຈໍາກັດ Extension ບໍ່ໃຫ້ເຮັດວຽກບາງໜ້າ ເຊັ່ນ `chrome://` ແລະ Chrome Web Store.
- ຖ້າໃຊ້ກັບໄຟລ໌ `file://`, ໃຫ້ເປີດ **Allow access to file URLs** ໃນລາຍລະອຽດ Extension ກ່ອນ.
- ບາງເວັບໄຊປ່ຽນ HTML ຫຼື class ເລື້ອຍໆ. ຖ້າ selector ເກົ່າບໍ່ກົງອີກ, ໃຫ້ເລືອກ element ເພື່ອສ້າງກົດໃໝ່.
